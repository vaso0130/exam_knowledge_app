系統管理

為了確保系統安全，所有管理操作僅限本地端執行

安全限制

基於安全考量，用戶管理、IP 黑名單等敏感操作只能在本機端執行。 請使用以下本地管理工具進行系統管理。

本地管理伺服器
推薦方式

啟動專用的本地管理界面，提供完整的 Web 管理功能：

F:/exam_knowledge_app/.venv/Scripts/python.exe admin_server.py
  • 用戶帳號管理
  • IP 黑名單管理
  • 安全記錄查看
  • 系統設定調整
  • 隨機埠口，僅本機存取
自動開啟瀏覽器，隨機端口確保安全
命令行工具
緊急使用

適用於緊急情況或系統維護：

F:/exam_knowledge_app/.venv/Scripts/python.exe admin_manager.py
  • 快速用戶操作
  • IP 黑名單管理
  • 系統重置功能
  • 批次處理操作
  • 完全離線執行
需要基本命令行操作知識
使用步驟
本地管理伺服器
  1. 開啟終端機或命令提示字元
  2. 進入系統目錄：
    cd f:\exam_knowledge_app
  3. 執行管理伺服器：
    F:/exam_knowledge_app/.venv/Scripts/python.exe admin_server.py
  4. 系統會自動開啟瀏覽器
  5. 使用管理員帳號登入
命令行工具
  1. 開啟終端機或命令提示字元
  2. 進入系統目錄：
    cd f:\exam_knowledge_app
  3. 執行管理工具：
    F:/exam_knowledge_app/.venv/Scripts/python.exe admin_manager.py
  4. 依照提示進行操作
  5. 選擇所需的管理功能
安全設計說明
僅限本機
管理功能只能在本機執行，無法遠端存取
隨機端口
每次啟動使用隨機端口，提高安全性
身分驗證
需要管理員帳號密碼才能操作
為什麼這樣設計？

這種設計確保了系統的最高安全等級： 敏感的管理操作完全隔離在本機端，避免了遠端攻擊的風險， 同時透過隨機端口和身分驗證提供額外的安全保障。
